This module provides an introduction to object orientated programming in Java. Topics include; classes, objects, inheritance, encapsulation, abstraction, polymorphism, file input and output and GUIs.

How to Run the Programs
Install the Java Development Kit (JDK).
Launch Visual Studio Code or terminal and access the relevant repository folder.
Access the relevant tutorial folder.
Compile Java files via:
`javac Main.java`
Execute the programme via:
`java Main`
For Tutorial 7, execute `QuizBattleGUI` to launch the GUI.
